College Academic Project

Event Booking Management System

A full-featured, responsive, client-side Web Application for discovery, seat reservation, real-time ticket generation, and event administration.

Project Objective

To design and engineer an intuitive end-to-end platform that enables users to browse live national & international events, choose seats visually, receive instantly generated QR-code tickets, and manage bookings locally without backend overhead.

Core Technologies

  • HTML5: Semantic UI Structure & Accessibility
  • CSS3: Custom Flexbox/Grid, Animations & Media Queries
  • JavaScript (ES6+): Async/Fetch API, LocalStorage Engine, DOM Manipulation
  • Ticketmaster API: Live Events REST Endpoint integration

How System Operates

1

Auth & Role

Users register & authenticate locally. Admin logs in with specialized permissions.

2

Live Fetch & Filter

Integrates with REST API for real-time events filtered by Indian States & Districts.

3

Visual Booking

Interactive seat matrix calculates exact total fare and convenience fees.

4

E-Ticket & QR

Generates unique Booking ID and Client-side QR code stored in LocalStorage.
